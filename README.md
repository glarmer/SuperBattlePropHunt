# PropHunt

Disguise yourself as a prop and don't let those pesky Hunters get you!

![prophuntgif](https://glarmer.xyz/images/prophunt.gif)

### Props:
- Press E to disguise as a Prop that you are looking at
- Press F to place a decoy of a Prop you are looking at
- Limited to a host set amount of disguises and decoys (3 each by default)!

### Hunters:
- Have developed infinite duelling gun technology!
- Take damage (10 by default, configurable by host) if they shoot a non-player prop!

### Details:
- Only the host can advance to the next hole, or end the game
- Gamemodes can be selected via the match menu dropdown:

![prophuntmatchmenudropdown](https://glarmer.xyz/images/prophunt.png)
